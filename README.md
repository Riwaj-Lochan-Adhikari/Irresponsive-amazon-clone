# Amazon Homepage Clone 🛒

An Amazon-inspired e-commerce homepage built using HTML and CSS. This project recreates Amazon's homepage layout, navigation, product sections, and visual design.

## 🌐 Live Demo

[(https://vercel.com/riwaj-lochan-adhikaris-projects/vercel-amazon-clone)](https://vercel-amazon-clone.vercel.app/)

##  Features

- Amazon-inspired navigation bar
- Search bar UI
- Product category sections
- Promotional banners
- Product display cards
- Footer section

 ##  Technologies Used

- HTML5
- CSS3


## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
